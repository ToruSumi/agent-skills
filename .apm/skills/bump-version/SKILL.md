# バージョンのインクリメント手順

## バージョンの管理場所

バージョンは基本的に **`pyproject.toml` の `[project] version`** で管理する。

```toml
# pyproject.toml
[project]
version = "1.3.0"   # ← ここだけ変更する
```

プロジェクトによっては、このバージョンをコード側（例: `get_project_version()` のような関数や
UIのバッジ表示など）で参照している場合がある。作業前に `grep` 等で他にバージョン文字列を
ハードコードしているファイルがないか確認し、あればあわせて更新する。

---

## セマンティックバージョニング（MAJOR.MINOR.PATCH）

| 種別    | 上げるケース                                               | 例                     |
| ------- | ---------------------------------------------------------- | ---------------------- |
| `PATCH` | バグ修正・小さな改善（後方互換あり）                       | `1.3.0` → `1.3.1`     |
| `MINOR` | 新しいビュー・機能の追加（後方互換あり）                   | `1.3.0` → `1.4.0`     |
| `MAJOR` | 破壊的変更（APIや出力フォーマットの非互換変更）            | `1.3.0` → `2.0.0`     |

`MINOR` を上げた場合は `PATCH` を 0 にリセットする。
`MAJOR` を上げた場合は `MINOR` と `PATCH` を両方 0 にリセットする。

---

## 手順

1. `pyproject.toml` を開く
2. `[project]` セクションの `version = "X.Y.Z"` を書き換える

```toml
[project]
name = "your-project-name"
version = "1.4.0"   # 変更後
```

3. 保存する（`pyproject.toml` 以外にバージョンを参照している箇所があれば、あわせて変更する）
